# kastruppro/tap

Homebrew tap for [brewau](https://github.com/kastruppro/brewau).

```sh
brew install --cask kastruppro/tap/brewau
```

brewau keeps itself up to date from this tap after each scheduled upgrade
(`sudo brewau self-update` updates at once). Remove it with `sudo brewau uninstall`,
not `brew uninstall`.

Everything in this tap runs with root on every Mac that trusts it, so only
maintainers push here.
